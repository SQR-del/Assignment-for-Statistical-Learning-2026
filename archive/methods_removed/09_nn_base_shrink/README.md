# 09 底座 + 第 4 名的收缩后处理（竞赛技巧，未采用）

**做法**：在底座的输出上，每行乘以 min(mean|p|^0.6, 1)，也就是让整体很弱的行进一步收缩、强行不变。

第 4 名原方案还会再乘一个放大系数 MULT（1.2–1.7）。这个系数是按排行榜调出来的，我们无法诚实地选择，所以这里不用。

**结论**：在我们的验证下有害，objective 从 0.957 变差到 0.982，因此不采用。

标签生成研究发现，MULT 的取值与我们实测的"少样本拟合 → 全样本拟合"中强化合物的放大倍数（1.2–1.8）吻合。这说明这个技巧在官方测试集上的收益，主要来自 B/Myeloid 训练标签与测试标签生成方式的差异，详见 `results/label_generation_study/`。
