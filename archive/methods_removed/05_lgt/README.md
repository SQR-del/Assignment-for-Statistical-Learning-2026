# 05 LGT：潜空间分块门控迁移（原实现，变体 L3）

**做法**：
- 预测值 = 目标锚点均值 + 来源门控项。
- 门控项的输入是查询化合物在各来源细胞中的响应，各自减去该来源在锚点上的均值。这些残差分两部分处理：
  - PCA 子空间内（K=4，分 4 块）：每块、每个来源各一个系数；
  - 子空间外：每个来源一个系数。
- 系数在锚点上用岭回归拟合。
- 超参数沿用原实验选出的 L3 配置：K=4，blocks=4，la=1，ld=1，lb=0.01。阳性对照全部排除。
- 本文件夹直接调用存档代码 `archive/code_lgt_20260930/lgt.py`，按原方式为每组可用来源单独建模。

**问题**（详见 2026-09-30 的评审）：
- **截距**：用的是锚点均值，会被强毒性化合物主导，参见 01。
- **丢失锚点**：匹配来源时，CD8+ 缺 Alvocidib 和 Oprozomib 两行，导致这两个最关键的锚点在大多数拟合中被丢弃。
- **超参数**：选择结果落在网格边界上。

**结果**：内部比全零还差，官方与全零几乎相同（0.901 对 0.902），是本组改用 KRR 的直接原因。原实验在它自己的协议下报告的分数是 A 1.039、B 2.344，与下表协议定义不同。

| A | A15 | V1 | V1w | objective |
|---:|---:|---:|---:|---:|
| 1.054 | 1.123 | 2.344 | 1.277 | 1.116 |
