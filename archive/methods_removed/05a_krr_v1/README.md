# KRR v1（局部 KRR 的第一版，已归档）

> 已归档：`methods/05a_krr_local` 现在使用 KRR v2 配置。v1 仍是内部 objective 的基准（v1 = 1.000）。v1 的官方分数是 private 0.830 / public 0.604（文件为 `krr_null_v1_kaggle_ids.csv`）。

**做法**：

ŷ_d = r_t + c·x̄_d + k(d, A) (K_AA + α·tr(K)/n·I)⁻¹ [ Y_tA − r_t − c·x̄_A ]

- **r_t**：目标锚点的逐基因中位数，即 null 参照（见 02）。
- **x̄_d**：查询化合物在来源细胞（NK、CD4+、Treg）中相对各自中位数的平均偏移，乘以 c 收缩后加入。这是"同化合物迁移"，04 说明了为什么必须收缩。
- **核项**：根据查询化合物与各锚点在来源细胞上的相似度（线性核），把锚点上"目标细胞特有的残差"迁移给查询化合物。这就是"锚点类比"：响应模式相似的化合物，在目标细胞里也应有相似的特有响应。
- **超参数**：c=0.2，α=10，只在协议 A 的内层任务上选出；阳性对照不参与。代码见 `code/krr.py`（version 1）。
