# 05a 局部 KRR（本组框架，KRR v2 配置）

**做法**：每个目标细胞单独拟合，训练标签只有该细胞的 15 个锚点（阳性对照不用）。代码见 `code/krr.py`（version 2）。

```
ŷ(t,d) = clip( r_t + c·P₆₄ x̄_d + Σ_{a∈A} k(d,a)·β_a )
```

- **r_t**：目标细胞锚点的逐基因中位数，即 null 参照。
- **c·P₆₄ x̄_d**：化合物在来源细胞（NK、CD4+、Treg）中的平均偏移，先投影到来源细胞的前 64 个主成分上去噪，再乘以 c 收缩。
- **Σ k(d,a)·β_a**：锚点类比项。按查询化合物与各锚点在来源细胞上的相似度（线性核），把锚点在目标细胞中"来源偏移解释不了"的那部分响应借过来。β 由岭回归闭式求出。
- **clip**：每个基因的预测值截断到可见数据的取值范围内。
- **参数**：c = 0.4，α = 3（λ = α·tr(K)/n），在内部协议上按预先声明的目标函数选出。

**和 KRR v1 的区别**：v1（c = 0.2，α = 10）不做主成分投影和截断，现已归档到 `archive/methods_removed/05a_krr_v1`，它是 objective 的基准（v1 = 1.000）。v2 去噪并截断后，可以迁移得更多、正则更弱。

**特点**：
- 在强锚点上是所有方法中最好的（V1 1.731）。
- 它也是 blend 中的 KRR 分量，权重 0.2，用来弥补神经网络在强化合物幅度上的不足。本方法导出的预测与 blend 中的这个分量完全相同。

| A | A15 | V1 | V1w | objective |
|---:|---:|---:|---:|---:|
| 0.946 | 0.995 | 1.731 | 1.133 | 0.990 |

**官方分数**（2026-10-14 赛后提交，用于评估已固定的方法，不用于选模型）：private 0.799 / public 0.594。提交文件保留 3 位小数，并用 7z 压缩。
- 它明显好于 KRR v1（0.830）和联合 KRR（0.823），也好于神经网络底座（0.813），与底座 + I1（0.798）相当。
- 内部验证却认为它不如神经网络底座（0.990 对 0.957）。这再次说明，内部验证低估了"强化合物幅度"上的优势，原因见 `results/label_generation_study/`。
