# 08 底座 + I2：幅度输出头（创新 2）

**做法**：把网络输出写成 z = m · u，方向和幅度分开建模。
- **u（方向）**：MLP 输出后归一化为单位向量。
- **m（幅度）**：log m = MLP(h) + β_c · log‖化合物编码‖ + γ_c，其中 β_c、γ_c 按细胞类型学习。

这样，强化合物的响应幅度可以随化合物在来源细胞中的强度增长，并按细胞类型缩放。而底座直接回归坐标，强行的幅度往往被平均掉。代码见 `code/nn.py`，变体 `base_I2`。

**结论**：
- **内部**：objective 0.937，强锚点的误差（V1）从底座的 2.088 降到 1.903。
- **官方**：相对底座提升 7.4%，是官方分数提升的主要来源。内部验证低估了它的作用，原因见 `results/label_generation_study/`。
