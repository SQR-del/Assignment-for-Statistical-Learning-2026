# 10 blend（最终模型）

**做法**：

blend = 0.4 · (底座 + I2) + 0.4 · (底座 + I1 + I2) + 0.2 · 局部 KRR

即 08、09 和 05a 三者的加权平均。两个网络共用同一份编码，各用 10 个种子训练。

**局部 KRR（05a，KRR v2 配置）**对强化合物幅度的把握比神经网络好：单独使用时 V1 为 1.731，是所有方法中最好的；官方分数 0.799。所以它和网络互补。

- **权重**：按预先声明的目标函数 mean(V1w / 1.1625, A15 / 0.9894) 选出，并在两次独立重复上确认（0.9254、0.9253）。没有使用排行榜。
- **与 `code/predict.py` 一致**：通过本文件夹的 `run.py --export` 生成的文件，与已提交的 blend_v1 最大差异为 1e-7，只是 CSV 的舍入误差。

**结论**：
- **内部**：objective 最低（0.927），A15 最好。
- **官方**：与 08 几乎相同（0.752 对 0.753）。内部 1.1% 的组合收益在官方测试集上基本没有体现。
