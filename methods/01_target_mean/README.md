# 01 目标细胞均值（基线）

**做法**：取目标细胞类型全部可见训练行（15 个锚点 + 2 个阳性对照）的逐基因均值，对所有化合物给出同一个预测。

**问题**：均值被少数强毒性化合物（Alvocidib、MLN 2238、Oprozomib）和阳性对照 Belinostat 主导，对大多数弱响应化合物严重高估，结果比全零还差一倍。这说明这个任务的参照点必须对极端值稳健。
