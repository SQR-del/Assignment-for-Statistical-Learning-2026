# 11 nn_v2 + I2

与 `08_nn_base_I2` 并列的新模型。代码是 `code/nn.py` 的副本 `code/nn_v2.py`，只改了一处：

- **细胞类型的目标编码由留一均值改为留一中位数。**

理由：一种细胞类型全部行的均值会被少数强药主导（B / 髓系只有 17 行，其中 2 行是阳性对照）。用中位数作参照是局部 KRR 的第一个有效改进，网络的输入此前仍用均值。

其余（降维、药物编码、网络结构、I2 幅度头、损失、随机种子）与 08 完全相同，所以两者的分数差只反映这一处改动。

```bash
diff ../../code/nn.py ../../code/nn_v2.py     # 查看全部改动
CUDA_VISIBLE_DEVICES=3 python run.py           # 内部验证
```
