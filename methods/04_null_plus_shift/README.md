# 04 null 参照 + 来源偏移（基线）

**做法**：以目标细胞的 null 参照为起点，加上该化合物在来源细胞中相对各自 null 的平均偏移：

ŷ_d = median_t(锚点) + mean_s [ y_s,d − median_s(共有化合物) ]

来源细胞为 NK、CD4+、Treg（不含目标细胞），所有中位数都不含阳性对照。它相当于 KRR 取 c = 1、并去掉锚点类比项。

**结论**：结果比 02、03 单独使用都差，主要坏在 A15 上（1.171）。把来源偏移原封不动地搬过来，会把强化合物的幅度搬错。所以迁移量必须收缩，KRR 中的 c 只取 0.2–0.4。
