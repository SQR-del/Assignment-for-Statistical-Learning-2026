# nn_v2 实验记录（2026-11-13）

目的：在 `code/nn.py` 的副本 `code/nn_v2.py` 上逐项做最小改动，找出对底座 + I2（`08_nn_base_I2`）有效的改动及其搭配。
规则：每次只改一处，与原模型比较；判断标准是事先定好的综合指标 objective（越低越好）；有效的再组合；最后换随机种子复核。不使用 Kaggle 分数。

脚本：`run_variant.py`（单个网络）、`run_blend.py`（融合）、`run_aligned.py`（对齐验证）、`compare.py`（对比）。结果在 `results/nn_v2_lab/`。
开关全关时与 `08_nn_base_I2` 逐行误差完全相同（`ref`）。

## 单项改动（原模型 0.9373，随机种子波动约 0.001）

| 改动 | objective | 结论 |
|---|---|---|
| K=32（输出维度 64 → 32） | 0.9287 | 有效 |
| K=48 / K=24 / K=16 | 0.9340 / 0.9305 / 0.9388 | 32 附近最好 |
| 训练 800 轮（400 → 800） | 0.9331 | 有效 |
| 训练 200 / 1600 轮 | 0.9429 / 0.9384 | 变差 |
| dropout 0.2（0.3 → 0.2） | 0.9351 | 略有效 |
| dropout 0.1 / 0.4 | 0.9366 / 0.9407 | 0.2 最好 |
| 输入噪声 0.05 / 0.2（原 0.1） | 0.9357 / 0.9385 | 0.05 略好，幅度在噪声范围内 |
| 隐藏层 256（原 512） | 0.9400 | 变差 |
| 细胞类型编码改中位数（全部 / 仅行数少的细胞） | 0.9419 / 0.9422 | 变差 |
| I2 幅度上限放宽 | 0.9373 | 无影响 |

## 组合与复核（三组随机种子）

| 配置 | objective（三组） | 平均 | 相对原模型 |
|---|---|---|---|
| 原模型 | 0.9373 0.9377 0.9357 | 0.9369 | |
| K=32 | 0.9287 0.9268 0.9271 | 0.9275 | −0.0094 |
| K=32 + 800 轮 + dropout 0.2 | 0.9222 0.9214 0.9222 | 0.9219 | −0.0150 |
| 再加输入噪声 0.05 | 0.9208 0.9191 0.9200 | 0.9200 | −0.0169 |

选定：**K=32 + 800 轮 + dropout 0.2**。再加噪声 0.05 的单网络优势为 0.002，放进融合后只剩 0.0005，且强锚点（V1）变差（1.61 对 1.54），不采用。

提升来自哪里：三组种子平均后的行级差，T/NK 协议 −0.019 [−0.046, +0.006]，弱锚点 −0.013 [−0.041, +0.014]，全部锚点 −0.37 [−0.84, −0.03]。
全部锚点的改善集中在 3 行（髓系 Alvocidib −5.3，B 细胞 Oprozomib −2.8，B 细胞 MLN 2238 −2.3）；去掉这 3 行后平均差为 −0.02。
即：强毒性药物上明显更好，其余基本持平。
