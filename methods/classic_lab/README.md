`improve_embed.py`，该文件不在分支中，无法移植；round2 的 embedding 即 `16_embedding`。

- `code/models_emb.py`、`code/common_emb.py`：分支 `code/models.py`、`code/common.py`（提交 3a87515）原样拷入，仅把 xgboost 改为可选导入。
