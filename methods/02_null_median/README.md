# 02 目标细胞中位数：null 参照（基线）

**做法**：对目标细胞类型的可见锚点（不含对照），逐基因取中位数，对所有化合物给出同一个预测。

**意义**：中位数不受少数强化合物影响，代表"一个典型的弱响应化合物"在这种细胞里的样子，也就是 null 参照。它在协议 A 上略好于全零。它也是局部 KRR（05a）的截距，是本组框架的出发点。

| A | A15 | V1 | V1w | objective |
|---:|---:|---:|---:|---:|
| 0.996 | 1.062 | 2.798 | 1.214 | 1.059 |
