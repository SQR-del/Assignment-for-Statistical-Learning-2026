# 06 神经网络底座（参考第 4 名方案）

**做法**（代码见 `code/nn.py`，变体 `base`）：
- **输入**：对可见标签做 TSVD（K=64，不中心化）。在主成分坐标上，分别计算细胞类型和化合物的留一目标编码（leave-one-out target encoding），作为网络输入。
- **噪声**：训练时对编码乘以 N(1, 0.1) 的噪声，模拟留一编码在测试时的误差。
- **网络**：8 个 MLP 同时训练（2 个隐层 × 512，GELU，dropout 0.3），输出 64 维主成分坐标。
- **损失**：精确的逐行 RMSE，包含子空间外的残差，与评价指标一致。AdamW，余弦学习率，训练 400 轮。
- **集成**：验证时用 3 个随机种子，导出时用 10 个，取中位数。

**特点**：
- 弱锚点上的误差大幅下降（V1w 从 KRR v1 的 1.163 降到 1.064）。
- 强锚点的幅度预测不足，V1 为 2.088，比 KRR 差。
- 在它的输出上加第 4 名的收缩后处理（每行乘 min(mean|p|^0.6, 1)），三项指标全部变差，objective 升到 0.982。该方法已从列表中移除，见 `archive/methods_removed/`。
