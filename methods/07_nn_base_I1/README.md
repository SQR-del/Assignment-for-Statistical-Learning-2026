# 07 底座 + I1：类比目标编码（创新 1）

**做法**：给底座增加一个输入，即"类比目标编码"。对行 (c, d)，分两步构造：
1. 用化合物 d 在**其他** T/NK 细胞中的响应，与各参考化合物（15 个锚点 + 2 个对照，不含 d）的响应做核岭回归，得到一组权重；
2. 用这组权重组合细胞 c 自身参考行的主成分坐标。

这样，目标细胞对 d 的响应，就由"在其他细胞里与 d 相似的化合物"在目标细胞中的表现来估计，相当于把 KRR 的锚点类比思想做成了网络输入。

训练行和测试行使用同一个参考集来构造：T/NK 的训练行也只用锚点和对照作参考。这样训练时和测试时的编码分布一致。代码见 `code/nn.py`，变体 `base_I1`。

**结论**：
- **内部**：相对底座，弱锚点上的误差下降 0.014（置信区间不含 0），其他指标基本不变。
- **官方**：同样有效，private 从 0.813 降到 0.798（−1.8%），public 0.588 是所有方法中最好的。
