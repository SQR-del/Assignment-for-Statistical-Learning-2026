# 5_official_scores：官方分数与内部验证的一致性（对应中期报告第 5 节）

## 文件
- **`kaggle_scores.csv`**：本项目在 Kaggle 上的全部 31 次提交，每次一行。

  | 列 | 含义 |
  |---|---|
  | `kaggle_file` | Kaggle 提交记录页上显示的文件名 |
  | `submitted` | 提交日期 |
  | `method_folder` / `method` | 对应的方法（`4_models/` 下的文件夹名）和中文名 |
  | `private` / `public` | 官方分数（MRRMSE，越低越好） |
  | `valid` | 分数是否有效 |
  | `precision` | 上传文件的数值精度 |
  | `uploaded_file` / `uploaded_sha256` | 实际上传的文件（在服务器上）和它的 sha256 |
  | `full_precision_file` | 同一方法用当前代码导出的全精度文件（在服务器上） |
  | `note` | 备注 |

- 每个方法的 `scores.json` 里的 `kaggle_*` 字段取自这里（该方法最近一次有效提交），由 `python 3_validation/harness.py` 刷新。

## 怎么理解这些分数
- **来源**：所有提交都是赛后提交（Late Submission），不进入排行榜，但会给出 private 和 public 两个分数。
- **private 与 public**：测试集共 255 行（129 个化合物 × B/髓系两种细胞），分成 public（约 50 个化合物）和 private（约 79 个化合物）两部分，以 private 为主。
- **无效提交**：最早 3 次提交的行顺序错误（用了 `data/id_map.csv` 的交错顺序，而不是 Kaggle 要求的 (cell_type, sm_name) 排序），分数无效，只作记录。
- **数值精度**：2026-10-13 至 10-14 的提交受上传大小限制，保留 3–4 位小数并用 7z 压缩，对分数的影响小于 0.0003；其余为全精度。
- **核对用提交**：`tmb_*` 两行是用分支 `singlecell-perturbation-project` 自己的导出流程生成的，只用于核对 21、22 号的移植，不对应方法文件夹。
- **用途**：官方分数只用于事后评估已经固定的方法，没有用来调参或选模型。
- **参照**：private 第 1 名 0.729，金牌线 ≤ 0.745，银牌线 ≤ 0.758，所有队伍的中位数 0.793。

各方法的官方分数与内部分数并列见 `4_models/README.md`。最终模型（`4_models/anchor_transfer/15_blend_v2`）为 private 0.734 / public 0.573。

## 内部验证能否预测官方分数

全部 21 个有官方分数的学习型模型（不含朴素基线），内部指标与官方分数的 Spearman 秩相关：

| 内部指标 | 与私有榜 | 与公开榜 | 两两排序与私有榜一致的比例 |
|---|---:|---:|---:|
| 协议 A | 0.72 | 0.87 | 77% |
| 协议 V（弱锚点） | **0.95** | 0.73 | **92%** |
| 协议 V（全部锚点） | 0.84 | 0.86 | 83% |
| 综合指标 | 0.93 | 0.86 | 90% |

- 协议 V 的弱锚点项与私有榜最一致：私有榜的药物大多是弱药物，而这一项测的正是在 B 和髓系细胞上预测弱药物。
- 协议 A 最弱。只看较强的 15 个模型时，弱锚点项与私有榜的秩相关为 0.88，协议 A 只有 0.29。
- 几个明显较差的经典方法扩大了分数范围，使上表的相关系数偏高。
- 官方分数没有被用来修改综合指标。协议 A 在 2026-11-16 改为计入全部四种 T/NK 细胞，是为了简化定义，与官方分数无关（改后协议 A 与官方分数的相关反而更低）。
