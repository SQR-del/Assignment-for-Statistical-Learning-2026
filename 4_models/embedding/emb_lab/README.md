# 把组员分支的模型接入统一验证（2026-11-15）

组员在分支 `singlecell-perturbation-project` 上独立完成了一套模型和验证。这里把其中最好的三个网络及其融合接入本仓库的验证框架，使两边的结果可以直接比较。

## 做法

- `src/nn_emb.py`：分支的 `src/nn.py`（提交 3a87515）原样拷入，只把 7 处 `.numpy()` 改为 `.cpu().numpy()`，使其能在 GPU 上运行。
- `src/emb_adapter.py`：适配层。从本仓库的表中只取可见行，整理成分支模型需要的输入（细胞与药物编号、SMILES 字符编码、药物签名），调用分支的训练函数。隐藏行是缺失值，误用会直接报错。
- 移植时的三个选择：保留 12 行阳性对照作为训练行（分支把它们删掉了）；保留分支"把预测截断到训练范围"的做法；随机种子个数用本仓库的约定。

## 第一步：在分支自己的协议下复现（`repro_p1.py`）

协议 P1：去掉阳性对照，四种 T/NK 细胞轮流作目标，训练集不含 B/髓系。四折平均：

| 模型 | 移植后 | 分支报告 |
|---|---|---|
| embedding | 0.904 | 0.899（5 个种子） |
| SMILES-CNN | 0.905 | 0.904 |
| embedding + 药物签名 | 0.937 | 0.937 |
| 融合 | 0.905 | 约 0.90 |
| 全零（分支未报告） | 1.006 | — |

差别都在 0.005 以内，移植没有改变模型的行为。分支报告里的线性、核、树等经典方法在 1.01–1.08，都不如全零。

## 第二步：在本仓库的 34 折上验证（`run_all.py`）

| 模型 | A | V1w | V1 | objective |
|---|---|---|---|---|
| 融合（原设置，`10`） | 0.921 | 1.026 | 1.842 | 0.9312 |
| 融合（新设置，`15`） | 0.919 | 1.015 | 1.551 | 0.9253 |
| 类别 embedding 网络（`16`） | 0.912 | 1.073 | 1.643 | 0.9463 |
| embedding + 药物签名（`17`） | 0.932 | 1.058 | 1.620 | 0.9506 |
| SMILES 字符 CNN（`18`） | 0.899 | 1.052 | 1.666 | 0.9306 |
| 分支的融合（`19`） | 0.907 | 1.062 | 1.627 | 0.9388 |

- 协议 A（把一种 T/NK 细胞当作新细胞）上，SMILES-CNN 和 embedding 好于本仓库的全部模型。
- B/髓系弱锚点（V1w）上，本仓库的网络更好（1.015–1.030 对 1.052–1.073）。
- 综合指标上，SMILES-CNN（0.9306）与原融合（0.9312）持平，略逊于新设置的融合（0.9253）。
- 行级配对的置信区间都包含 0（见 `results/emb_lab/`），两边的差别在统计上分不开。
- 各折的预测保存在 `results/emb_lab/preds/`，可用于跨两套模型的融合而不必重新训练。

分支的超参数是在它自己的四折（四种 T/NK 细胞）上调的，与协议 A 是同一批细胞，因此它在协议 A 上的分数带有选择偏差；本仓库"新设置"的三项超参数同样是在这 34 折上选的。
