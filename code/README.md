# 单细胞扰动预测：锚点类比 KRR + 神经网络底座 + 两项创新（blend）

NeurIPS 2023 Kaggle "Open Problems – Single-Cell Perturbations"：由 T/NK 细胞（NK、CD4+、CD8+、Treg）的差异表达结果，预测 B 细胞和 Myeloid 细胞对 129 个化合物的 signed −log10 p（18,211 个基因，255 行）。评价指标为 MRRMSE（逐行 RMSE 的均值）。

训练数据中，B 和 Myeloid 各只有 17 行（15 个"锚点"化合物 + 2 个阳性对照）。所有模型选择只使用训练标签和我们自己的内部验证，没有使用官方测试标签，也没有按排行榜调参。

## 最终模型

```
blend = 0.4 · (底座 + I2) + 0.4 · (底座 + I1 + I2) + 0.2 · KRR v2
```

| 组成 | 文件 | 说明 |
|---|---|---|
| 底座 | `nn.py` | 参考第 4 名方案：先对可见标签做 TSVD（K=64，不中心化），用细胞类型和化合物的留一目标编码作输入；对训练编码加乘性噪声 N(1, 0.1)；8 个 MLP 同时训练（2 个隐层 × 512，dropout 0.3，AdamW，余弦学习率，400 epoch）；损失为精确的逐行 MRRMSE，包含子空间外残差 |
| I1 类比目标编码（创新 1） | `nn.py` | 对行 (c, d)：先按 d 在**其他** T/NK 细胞中与各参考化合物的相似度，做核岭回归得到权重；再用这组权重组合 c 自身的参考行（15 个锚点 + 2 个对照，不含 d）。训练行和测试行按同一方式构造 |
| I2 幅度输出头（创新 2） | `nn.py` | z = m·u，其中 ‖u‖=1，log m = MLP(h) + β_c·log‖化合物编码‖ + γ_c。方向和幅度分开建模，β、γ 按细胞类型学习 |
| KRR v2（本组框架） | `krr.py` | 以目标锚点的逐基因中位数为 null 参照，锚点间的类比关系用来源细胞谱上的线性核岭回归；c=0.4，α=3，同化合物迁移项投影到前 64 个来源主成分，输出截断到可见范围。来源为 NK/CD4+/Treg，两个阳性对照不参与 |

- 权重 0.4/0.4/0.2 是按预先声明的内部目标选出的，并在两次独立重复上确认（0.9254、0.9253；单模型"底座 + I2"为 0.936）。
- 神经网络每个组成部分都用 10 个随机种子训练，每个种子是 8 个网络的集成，最后对种子取中位数。

## 文件

| 文件 | 内容 |
|---|---|
| `common.py` | 读取数据、建索引、Kaggle 提交顺序、写提交文件并校验 |
| `krr.py` | KRR v1 / v2 |
| `nn.py` | 目标编码、I1、I2、网络训练与集成 |
| `validate.py` | 内部验证：底座、两项创新、KRR 和 blend 的消融，输出到 `results/validation/` |
| `krr_joint.py` | 联合 KRR（对照实验）：所有细胞一起拟合，输入和训练行与神经网络底座相同；不属于最终模型，见 `methods/05b_krr_joint` |
| `predict.py` | 用全部 614 行训练，生成 255 行预测，输出到 `results/blend_final/` |

## 运行

需要一块 CUDA GPU（在 A40 上测试）。依赖见 `requirements.txt`，测试时的版本为 torch 2.10、numpy 2.2、scipy 1.15、pandas 2.3。

```bash
python predict.py
```

约 75 秒，生成 `results/blend_final/blend_kaggle_ids.csv` 以及三个组成部分的文件。

```bash
python validate.py
```

约 7 分钟，生成 `results/validation/rows.csv` 和 `summary.json`。

`predict.py` 每次都会做泄漏检查：把测试行的占位标签分别设为 0 和 1e5，要求所有组成部分的预测完全相同（实测差异为 0）。它还会与之前导出的文件比较：与已提交的 `blend_v1` 最大差异为 8.8e-8，只是 CSV 保存精度带来的舍入误差。

## 内部验证（`validate.py` 输出）

- **协议 A**：依次留出一种 T/NK 细胞，只保留它的 15 个锚点和 2 个对照，预测它的官方测试化合物。A15 是去掉 CD8+ 后的结果（CD8+ 缺 2 个锚点）。
- **协议 V1**：在 B/Myeloid 上逐个留出锚点。V1w 只统计在来源细胞中响应较弱的锚点，它们更像大多数测试化合物。
- **目标函数**：objective = mean(V1w / 1.1625, A15 / 0.9894)。分母是 KRR v1 的值，所以 KRR v1 = 1.000。这个目标在运行任何神经网络之前就已确定。

| 模型 | A | A15 | V1 | V1w | objective |
|---|---:|---:|---:|---:|---:|
| **blend** | 0.921 | 0.960 | 1.842 | 1.026 | **0.927** |
| 底座 + I2 | 0.937 | 0.978 | 1.903 | 1.030 | 0.937 |
| 底座 + I1 + I2 | 0.949 | 0.986 | 1.990 | 1.024 | 0.939 |
| 底座 + I1 | 0.937 | 0.988 | 2.104 | 1.050 | 0.951 |
| 底座 | 0.938 | 0.988 | 2.088 | 1.064 | 0.957 |
| 底座 + 第 4 名后处理（收缩） | 0.952 | 1.007 | 2.117 | 1.100 | 0.982 |
| KRR v2 | 0.946 | 0.995 | 1.731 | 1.133 | 0.990 |
| KRR v1 | 0.940 | 0.989 | 1.890 | 1.163 | 1.000 |

## 注意事项

- **提交顺序**：Kaggle 要求按 (cell_type, sm_name) 排序，id 0–127 为 B 细胞，128–254 为 Myeloid。`data/id_map.csv` 本身的行序与此不同，是 B/Myeloid 交错排列，不能直接使用；`common.Table.kaggle` 已经处理。
- **内部验证的局限**：内部验证能判断方向，但会低估幅度建模的作用。I2 相对底座的提升，内部 objective 是 −2.1%，官方 private 是 −7.4%。
- **标签生成研究（`results/label_generation_study/`）**：用原始计数复现了组织方的 limma 流程，确认 B/Myeloid 训练标签只用训练孔拟合（自由度约 130），而测试标签来自全样本拟合（约 380）。但把锚点按自由度校正到测试尺度会让 blend 变差（+0.007），因此没有采用。
- **旧代码**：原 LGT 代码已移到 `archive/code_lgt_20260930/`。`results/krr_null_v1/`、`results/krr_v2/` 里的旧脚本依赖其中的 `experiment.py`。
